## Separate positive opaque HTTPS tunnel
Start scripts/linux/egress_tls_tunnel_fixture.py serve --cert /private/test-leaf.pem --key /private/test-key.pem. Operator provides a test-only certificate for bushido-tunnel.test, trusted by the disposable browser profile/account (do not install a fixture CA in ordinary trust stores or disable TLS validation). Use the printed proxy port with the existing fresh XDG constructor, visit https://bushido-tunnel.test/. Only exact CONNECT bushido-tunnel.test:443 with matching Host admitted; fixed numeric loopback destination is the ephemeral synthetic origin, not a caller-provided address. Separate original sentinel still denies all CONNECT. Proxy is opaque, origin terminates TLS, no external forwarding or DNS; counts distinguish CONNECT, relayed bytes, and origin HTTP. 12-second total/2 MiB each-direction relay bound; single connection at a time. Some WebKit proxy headers may not meet the intentionally narrow admission; native runtime compatibility OPEN. Negative certificate/name/trust and dead-origin controls required. Compare actual peer process/packet observations and prove no bypass independently. No fixture trust changes automated.

The real resolver now has a private direct-address candidate constructor on ResolverControl. It uses the same strict wire shape and existing Hickory query/response checks, original primary DoH call (no cache/fallback), blocklist, expiry and policy generation. scoped_destination only constructs numeric port-443 socket address if exact hostname, independently approved IP, generation and expiry match. It is not a socket capability, does not dial, does not establish certificate validity or classify IP safety; no IPC callers. Address scope approval must be trusted and independent; shared resolver identity, policy dispatch/revocation, public/private destination validation and real live DNS-to-tunnel weld remain OPEN. The positive tunnel is deliberately synthetic; these two modules are not yet connected. Five regression tests written (three Python, two Rust), not executed.
